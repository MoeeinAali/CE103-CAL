# Lab 06 — واحد محاسبه با امکان انتخاب ثبات مبدا و مقصد

واحد محاسبات و مجموعه ثبات‌های عمومی ماشین: جمع و تفریق با انتخاب ثبات مبدا،
ثبات مقصد و مقادیر ثابت، طبق شکل‌های ۸ و ۹ دستور کار.

| | |
|---|---|
| فایل مدار | [`alu_regfile.circ`](alu_regfile.circ) |
| مدارها | `datapath` (طراحی اصلی) و `main` (دمو با Clock) |
| قطعات اصلی | ۱ × Adder، ۱ × Multiplexer (۸ به ۱)، ۴ × Register، ۱۴ گیت |
| تست | هر ۵۶ فرمان معتبر + برنامه‌های تصادفی — همه پاس |

## قالب فرمان

فرمان ۶ بیتی است:

```
  [ F | D1 D0 | S2 S1 S0 ]
    5   4   3   2  1  0
```

| میدان | بیت‌ها | معنی |
|---|---|---|
| `F` | ۵ | ۰ = جمع، ۱ = تفریق |
| `D` | ۴:۳ | ثبات مقصد: `00`=R0، `01`=R1، `10`=R2، `11`=R3 |
| `S` | ۲:۰ | مبدا: `000..011`=R0..R3، `100`=۰، `101`=۱، `110`=۱−، `111`=رزرو |

عملیات انجام‌شده همیشه به این شکل است:

```
Rd  <-  R0  (+/-)  src
```

یعنی یک عملوند ALU همیشه محتوای R0 است و عملوند دیگر با میدان `S` انتخاب می‌شود.

## رابط مدار

| سیگنال | جهت | پهنا | توضیح |
|---|---|---|---|
| `IR` | ورودی | ۶ | فرمان |
| `WE` | ورودی | ۱ | فعال‌ساز نوشتن؛ ۰ یعنی هیچ ثباتی تغییر نکند |
| `clk` | ورودی | ۱ | لبه‌ی بالارونده |
| `rst` | ورودی | ۱ | پاک‌سازی آسنکرون همه‌ی ثبات‌ها |
| `R0`..`R3` | خروجی | ۸ | محتوای ثبات‌ها |
| `ALUout` | خروجی | ۸ | خروجی ALU (برای مشاهده) |
| `Cout` | خروجی | ۱ | رقم نقلی خروجی (برای مشاهده) |

## معماری

```
        ┌──────────────┐
  IR ──▶│  رمزگشایی    │── F ──────────────┐
        │   فرمان      │── D ──▶ decode ──┐│
        └──────────────┘── S ──┐          ││
                               ▼          ││
   R0,R1,R2,R3,0,1,-1 ──▶ [ MUX 8:1 ]     ││
                               │ src      ││
                               ▼          ││
                          [ XOR × 8 ]◀── F ││   (تفریق = متمم یک + رقم نقلی)
                               ▼          ││
              R0 ──────▶ [ 8-bit Adder ]◀─┘│   Cin = F
                               │ result    │
                               ▼           ▼
                        ┌──────────────────────┐
                        │  R0   R1   R2   R3   │  ← فقط ثبات انتخاب‌شده
                        └──────────────────────┘     بارگذاری می‌شود
```

### جمع و تفریق با یک جمع‌کننده

تفریق به‌صورت متمم دو انجام می‌شود:

```
F = 0 :  R0 + src
F = 1 :  R0 + (~src) + 1  =  R0 - src
```

پس هر بیت مبدا با `F` گیت `XOR` می‌شود و خود `F` به‌عنوان رقم نقلی ورودی
(`Cin`) به جمع‌کننده داده می‌شود. با این کار **یک جمع‌کننده‌ی ۸ بیتی هر دو
عمل را انجام می‌دهد** و به مدار تفریق جداگانه نیازی نیست.

### انتخاب مقصد

رمزگشای ۲ به ۴ با گیت ساخته شده است:

```
EN_k = WE · (D1 == k1) · (D0 == k0)
```

هر چهار ثبات خروجی ALU را روی ورودی `D` و ساعت مشترک می‌بینند، ولی فقط ثباتی
که `EN` آن یک است در لبه‌ی ساعت بارگذاری می‌شود. مکمل بیت‌های مقصد با
`XOR(x, 1)` ساخته شده، چون در Lab02 معلوم شد گیت `NOT` تولیدشده گاهی بی‌صدا
از فایل حذف می‌شود.

نکته: چون ثبات‌ها لبه‌ای هستند، وقتی مقصد و مبدا یکی باشند (مثلا
`R0 <- R0 + R0`) مقدار **قبلی** ثبات خوانده می‌شود و مشکلی پیش نمی‌آید.

## نحوه‌ی استفاده

۱. `rst` را یک لحظه ۱ کن تا همه‌ی ثبات‌ها صفر شوند.
۲. فرمان را روی `IR` بگذار (در `main` سه میدان `F`/`DST`/`SRC` جدا هستند).
۳. `WE` را ۱ کن.
۴. یک لبه‌ی ساعت بده — فرمان اجرا می‌شود و نتیجه در ثبات مقصد می‌نشیند.

هر لبه‌ی ساعت دقیقا یک فرمان اجرا می‌کند. با `WE = 0` هیچ ثباتی تغییر نمی‌کند،
که برای توقف یا تک‌گام‌کردن مفید است.

مثال — محاسبه‌ی `R1 = R0 + 1` سپس `R2 = R0 - R1`:

| فرمان | باینری | معنی |
|---|---|---|
| `0x0D` | `001101` | `R1 <- R0 + 1` |
| `0x31` | `110001` | `R2 <- R0 - R1` |

## هندسه‌ی قطعات (یافته‌ی مهم این آزمایش)

مختصات پورت قطعات کتابخانه‌ای در لاجسیم آن چیزی نیست که حدس اول می‌گوید. همه‌ی
مقادیر زیر با بردار تست واقعی روی همین نسخه (v4.1.0) **آزمایش و تأیید** شده‌اند:

| قطعه | پورت‌ها (نسبت به `loc`) |
|---|---|
| `Adder` | `A(-40,-10)`، `B(-40,+10)`، `Sum(0,0)`، `Cin(-20,-20)`، `Cout(-20,+20)` |
| `Register` | `D(0,30)`، `Q(60,30)`، `clk(0,70)`، `en(0,50)`، `rst(30,90)`؛ بدنه ۶۰×۹۰ |
| `Multiplexer` (۲ ورودی) | `in0(-30,-10)`، `in1(-30,+10)`، `sel(-20,+20)`، `out(0,0)` |
| `Multiplexer` (n>2) | `in_i(-40, -(n/2)·10 + 10i)`، `sel(-20, +(n/2)·10)`، `out(0,0)` |
| گیت‌ها | `in0(-30,-10)`، `in1(-30,+10)`، `out(0,0)` — **فقط با `size=30`** |

دو تله‌ی گران‌قیمت:

- **مالتی‌پلکسر بیش از ۲ ورودی عرض ۴۰ دارد نه ۳۰**، و گام ورودی‌هایش ۱۰ است نه
  ۲۰. با فرض اشتباه، خروجی همیشه `U` می‌ماند بدون هیچ پیام خطایی.
- **گیت با `size=50` با این مختصات کار نمی‌کند**؛ همیشه `size=30` بگذارید.

مختصات `Decoder` را نتوانستیم دربیاوریم (چند حالت مختلف امتحان شد و همه شکست
خورد)، برای همین رمزگشای مقصد با گیت `AND` ساخته شد که هم آزمایش‌شده است و هم
برای گزارش خواناتر.
