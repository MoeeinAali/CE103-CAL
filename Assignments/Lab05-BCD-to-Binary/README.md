# Lab 05 — تبدیل BCD سه‌رقمی به دودویی

مبدل ترتیبی BCD به باینری با الگوریتم شیفت راست و تفریق ۳
(معکوس Double-Dabble)، ساخته‌شده کاملا از تراشه‌های سری ۷۴ کتابخانه‌ی TTL لاجسیم.

| | |
|---|---|
| فایل مدار | [`bcd_to_binary.circ`](bcd_to_binary.circ) |
| مدارها | `converter` (طراحی اصلی) و `main` (دمو با Clock) |
| تراشه‌ها | ۱۶ عدد: `74194`×۶، `74283`×۳، `74157`×۳، `74161`، `7404`، `7408`، `7432` |
| تست | هر ۱۰۰۰ ورودی ممکن (۰۰۰ تا ۹۹۹) + دمو — همه پاس |

## رابط

| سیگنال | جهت | پهنا | توضیح |
|---|---|---|---|
| `A` | ورودی | ۱۲ | عدد BCD سه‌رقمی: `A[11:8]` صدگان، `A[7:4]` دهگان، `A[3:0]` یکان |

در مدار `main` به‌جای یک ورودی ۱۲ بیتی، **سه ورودی ۴ بیتی جدا** (`A2` صدگان،
`A1` دهگان، `A0` یکان) گرفته می‌شود و هر کدام روی یک نمایشگر هفت‌قطعه‌ای
(`Hex Digit Display`) نشان داده می‌شود. این سه نیبل با یک Splitter به باس
۱۲ بیتی `A` تبدیل و به مدار `converter` داده می‌شوند.
| `Start` | ورودی | ۱ | سطحی؛ شروع عملیات |
| `clk` | ورودی | ۱ | لبه‌ی بالارونده |
| `B` | خروجی | ۱۰ | معادل دودویی (۰ تا ۹۹۹) |
| `End` | خروجی | ۱ | با معتبرشدن `B` فعال می‌شود |

خروجی ۱۰ بیت است چون بیشترین ورودی ۹۹۹ = `11 1110 0111` است.

## الگوریتم

طبق دستورکار، در هر تکرار:

الف) کل ثبات BCD یک بیت به راست شیفت می‌شود؛ بیتی که از کم‌ارزش‌ترین رقم بیرون
می‌افتد، از سمت پرارزش وارد ثبات باینری می‌شود.

ب) هر رقمی که پس از شیفت پرارزش‌ترین بیتش ۱ باشد، ۳ واحد از آن کم می‌شود.

ج) این کار ۱۰ بار تکرار می‌شود؛ در پایان همه‌ی ارقام BCD صفر شده‌اند و ثبات
باینری جواب را نگه داشته است.

ردیابی دستی برای `A = 999`:

| تکرار | صدگان | دهگان | یکان | ثبات باینری |
|---|---|---|---|---|
| اولیه | 9 | 9 | 9 | `00 0000 0000` |
| ۱ | 4 | 9 | 9 | `10 0000 0000` |
| ۲ | 2 | 4 | 9 | `11 0000 0000` |
| ۳ | 1 | 2 | 4 | `11 1000 0000` |
| ۴ | 0 | 6 | 2 | `01 1100 0000` |
| ۵ | 0 | 3 | 1 | `00 1110 0000` |
| ۶ | 0 | 1 | 5 | `10 0111 0000` |
| ۷ | 0 | 0 | 7 | `11 0011 1000` |
| ۸ | 0 | 0 | 3 | `11 1001 1100` |
| ۹ | 0 | 0 | 1 | `11 1100 1110` |
| ۱۰ | 0 | 0 | 0 | `11 1110 0111` |

نتیجه `11 1110 0111 = 999` ✓

## نکته‌ی اصلی طراحی: تفریق ۳ بدون هیچ گیتی

اگر پرارزش‌ترین بیت ۱ است، ۳ کم کن یعنی در حساب ۴ بیتی ۱۳ اضافه کن
(متمم دوی ۳−). پس یک `74283` کافی است و ورودی دوم جمع‌کننده باید `1101` باشد
وقتی MSB برابر ۱ است.

اما پرارزش‌ترین بیت رقم **شیفت‌شده** دقیقا همان بیتی است که از رقم بالاتر وارد
می‌شود (`s`). بنابراین:

```
A4 = s    A3 = b3   A2 = b2   A1 = b1        (رقم شیفت‌خورده)
B4 = s    B3 = s    B2 = GND  B1 = s         (وقتی s=1 مقدار 1101 = 13)
Cin = GND
```

`s` خودش خروجی `Q` یک ثبات دیگر است، پس **تصحیح تفریق ۳ هیچ گیت اضافه‌ای لازم
ندارد** — فقط سه پین جمع‌کننده به همان سیم وصل می‌شوند.

## معماری

هر رقم BCD سه تراشه دارد:

```
        ┌─────────┐   b3..b0   ┌─────────┐  تصحیح‌شده  ┌─────────┐
 CLK ──▶│  74194  │───────────▶│  74283  │───────────▶│  74157  │
        │  ثبات   │            │ شیفت+−۳ │            │  مالتی  │
        └─────────┘            └─────────┘            └─────────┘
             ▲                       ▲                      │
             │                       │ s (بیت ورودی)        │ Start ? A : تصحیح‌شده
             └───────────────────────┴──────────────────────┘
```

| مرجع | تراشه | نقش |
|---|---|---|
| U1، U2، U3 | 74194 | ثبات ارقام صدگان، دهگان، یکان |
| U4، U5، U6 | 74283 | شیفت راست + تفریق ۳ برای هر رقم |
| U7، U8، U9 | 74157 | انتخاب `Start ? A : مقدار تصحیح‌شده` |
| U10، U11، U12 | 74194 | ثبات ۱۰ بیتی نتیجه‌ی باینری (شیفت راست) |
| U13 | 74161 | شمارنده‌ی تکرار، تا ۱۰ می‌شمارد |
| U14 | 7404 | `nCLR = !Start` و `RUN = !End` |
| U15 | 7408 | `End = Cq3 · Cq1` (شمارنده به ۱۰ رسید) |
| U16 | 7432 | `LD = Start + RUN` |

هیچ گیت مجزایی خارج از بسته‌های TTL استفاده نشده؛ فقط دو `Constant` برای
`VCC` و `GND`.

## واحد کنترل

```
nCLR = NOT(Start)        ثبات نتیجه و شمارنده را پاک می‌کند
RUN  = NOT(End)          تا رسیدن شمارنده به ۱۰ فعال است
LD   = Start OR RUN      ثبات ارقام هر سیکل بارگذاری می‌شود
End  = Cq3 AND Cq1       شمارنده به 1010 = ۱۰ رسید
```

| فاز | Start | End | ثبات ارقام | ثبات نتیجه | شمارنده |
|---|---|---|---|---|---|
| بارگذاری | ۱ | ۰ | **بارگذاری A** | پاک با `nCLR` | پاک با `nCLR` |
| اجرا | ۰ | ۰ | **بارگذاری مقدار تصحیح‌شده** | **شیفت راست** | می‌شمارد |
| پایان | ۰ | ۱ | نگه‌داری | نگه‌داری | ثابت روی ۱۰ |

## نمایش روی مدار `main`

| نمایشگر | چه چیزی نشان می‌دهد |
|---|---|
| سه نمایشگر بالا-چپ | ارقام ورودی BCD: صدگان، دهگان، یکان |
| سه نمایشگر بالا-راست | نتیجه‌ی باینری به‌صورت هگز: `B[9:8]`، `B[7:4]`، `B[3:0]` |
| پین `End` | پایان تبدیل |

نتیجه‌ی ۱۰ بیتی به‌صورت سه رقم هگز نشان داده می‌شود (۴+۴+۲ بیت). مثلا برای
ورودی ۹۹۹ خروجی `3 E 7` است که همان `11 1110 0111` = ۹۹۹ می‌شود.

## نحوه‌ی استفاده

۱. سه ورودی `A2`، `A1`، `A0` را روی ارقام عدد بگذار (مثلا ۹، ۹، ۹ برای ۹۹۹).
   در مدار `converter` به‌جایش `A` را روی `0x999` بگذار.
۲. `Start` را ۱ کن و یک لبه‌ی ساعت بده — `A` وارد ثبات ارقام می‌شود.
۳. `Start` را ۰ کن.
۴. ده لبه‌ی ساعت دیگر بده. پس از لبه‌ی دهم `End = 1` می‌شود و `B` جواب را دارد.

مجموعا ۱۱ لبه‌ی ساعت. در مدار `main` یک قطعه‌ی `Clock` واقعی هست؛ با `Ctrl+K`
می‌توانی آن را تیک بزنی.

> برای پیاده‌سازی روی بورد با اعداد دو رقمی (طبق دستورکار)، کافی است رقم صدگان
> `A[11:8]` را صفر بگذاری؛ بقیه‌ی مدار بدون تغییر کار می‌کند.

## تله‌ای که در این آزمایش خوردیم

ترتیب پین‌های خروجی `74161` در لاجسیم از پین ۱۱ به بالا **`Qd Qc Qb Qa`** است،
یعنی پین ۱۱ پرارزش‌ترین بیت است و پین ۱۴ کم‌ارزش‌ترین. این برعکس چیزی است که
از روی دیتاشیت انتظار می‌رود و برعکس `74194` هم هست.

با نگاشت اشتباه، شمارنده به‌جای ۱، ۲، ۳ دنباله‌ی ۸، ۴، ۱۲ را می‌شمرد و `End`
خیلی زود بالا می‌آمد (۷۷ خطا از ۲۸۶ گام). ترتیب درست از خود بایت‌کد لاجسیم
درآمد:

```bash
javap -p -c com/cburch/logisim/std/ttl/Ttl74161.class | grep 'String Q'
```

## چیدمان و سیم‌کشی

تراشه‌ها با `facing = south` (عمودی) چیده شده‌اند تا پین‌ها روی دو لبه‌ی چپ و
راست بیفتند. هر پین با یک استاب کوتاه به یک تونل نام‌دار می‌رود و طول استاب‌ها
یک‌درمیان ۳۰ و ۹۰ است تا بدنه‌ی تونل‌های هم‌سطح ۴۰ واحد فاصله بگیرند.

فایل با اسکریپت [`build_circ.py`](build_circ.py) تولید می‌شود؛ همان اسکریپت
بررسی هندسی هم می‌کند: هم‌پوشانی هم‌راستای سیم‌ها، اتصال T ناخواسته بین دو نت،
برخورد جعبه‌ی قطعات، و عبور سیم از داخل بدنه‌ی تراشه. هر چهار بررسی روی فایل
نهایی پاک است.

```bash
python3 build_circ.py     # تولید مدار + بررسی هندسی
python3 gen_vectors.py    # تولید بردارهای تست
```
