# Lab 03 — ضرب‌کننده دودویی ۴×۴ به روش Shift & Add

ضرب‌کننده‌ی ترتیبی چهاربیتی، ساخته‌شده کاملاً از تراشه‌های سری ۷۴ (کتابخانه‌ی TTL لاجسیم).

| | |
|---|---|
| فایل مدار | [`multiplier.circ`](multiplier.circ) |
| مدارها | `multiplier` (طراحی اصلی) و `main` (دموی با Clock) |
| تراشه‌ها | ۶ عدد: `7408`, `74283`, `74194` ×۲, `74161`, `7404` |
| تست | ۲۵۶ ضرب ممکن + ۶ سناریوی دمو — همه پاس |

## رابط

| سیگنال | جهت | پهنا | توضیح |
|---|---|---|---|
| `A` | ورودی | ۴ | مضروب |
| `B` | ورودی | ۴ | مضروب‌فیه |
| `start` | ورودی | ۱ | سطحی؛ برای مقداردهی اولیه فعال می‌شود |
| `clk` | ورودی | ۱ | لبه‌ی بالارونده |
| `C` | خروجی | ۸ | حاصل‌ضرب |
| `end` | خروجی | ۱ | با معتبرشدن `C` فعال می‌شود |

## الگوریتم

ثبات‌ها: `ACC[3:0]` (انباره)، `Q[3:0]` (مضروب‌فیه)، `M[3:0] = A` (مضروب، روی پین‌های ورودی ثابت).

هر سیکل **جمع و شیفت را با هم** در یک لبه‌ی ساعت انجام می‌دهد:

```
{Cout, S[3:0]} = ACC + (Q0 ? M : 0)
ACC ← {Cout, S3, S2, S1}
Q   ← {S0,   Q3, Q2, Q1}
```

پس از ۴ تکرار: `C[7:4] = ACC` و `C[3:0] = Q`.

ردیابی دستی برای `A = 3, B = 3`:

| سیکل | ACC | Q | Q0 | جمع |
|---|---|---|---|---|
| اولیه | 0000 | 0011 | — | — |
| ۱ | 0001 | 1001 | ۱ | 0_0011 |
| ۲ | 0010 | 0100 | ۱ | 0_0100 |
| ۳ | 0001 | 0010 | ۰ | 0_0010 |
| ۴ | 0000 | 1001 | ۰ | 0_0001 |

نتیجه `0000_1001 = 9` ✓

## تراشه‌ها

| مرجع | تراشه | نقش |
|---|---|---|
| U1 | 7408 | چهار گیت AND دو ورودی — `M_i = A_i · Q0` |
| U2 | 74283 | جمع‌کننده ۴ بیتی — `ACC + M` با `CIN = GND` |
| U3 | 74194 | ثبات ACC — بارگذاری موازی `{Cout,S3,S2,S1}` |
| U4 | 74194 | ثبات Q — بارگذاری `B`، سپس شیفت راست با ورودی سریال `S0` |
| U5 | 74161 | شمارنده‌ی ۴ سیکل — تولید `end` |
| U6 | 7404 | اینورتر شش‌تایی — دو گیت استفاده شده: `nST`, `RUN` |

هیچ گیت مجزایی خارج از بسته‌های TTL استفاده نشده است. دو قطعه‌ی `Constant`
سطح منطقی ۱ (`VCC`) و ۰ (`GND`) را برای پین‌های tie-off تأمین می‌کنند.

## واحد کنترل

نکته‌ی طراحی: پین‌های مُد خود `74194` کل کنترل را می‌سازند و هیچ فلیپ‌فلاپ اضافه‌ای لازم نیست.

```
RUN = NOT(end)      nST = NOT(start)          (هر دو از U6)

U3 (ACC): S1 = S0 = RUN      , nCLR = nST
U4 (Q)  : S1 = start, S0 = RUN, nCLR = VCC
U5 (cnt): ENP = ENT = RUN    , nLOAD = VCC , nCLR = nST
end = U5.QC                   (شمارنده به ۴ رسیده ⇒ بیت ۲)
```

کدگذاری مُد `74194` روی `S1 S0`: `11` بارگذاری موازی، `01` شیفت راست، `00` نگه‌داری.

| فاز | start | end | مُد ACC | مُد Q | شمارنده |
|---|---|---|---|---|---|
| بارگذاری | ۱ | ۰ | پاک با `nCLR` | **بارگذاری B** | پاک با `nCLR` |
| اجرا | ۰ | ۰ | **بارگذاری نتیجه‌ی جمع** | **شیفت راست** | می‌شمارد |
| پایان | ۰ | ۱ | نگه‌داری | نگه‌داری | ثابت روی ۴ |

## نحوه‌ی استفاده

۱. `start` را ۱ کن.
۲. یک لبه‌ی ساعت بده — `B` وارد `Q` می‌شود؛ `ACC` و شمارنده به‌صورت آسنکرون صفر می‌مانند.
۳. `start` را ۰ کن.
۴. چهار لبه‌ی ساعت دیگر بده. پس از لبه‌ی چهارم `end = 1` می‌شود و `C` حاصل‌ضرب را نگه می‌دارد.

مجموعاً ۵ سیکل ساعت. `C` همیشه از `{ACC, Q}` رانده می‌شود، پس مقادیر میانی هم
در حین اجرا قابل مشاهده‌اند و مقدار نهایی دقیقاً هم‌زمان با بالا رفتن `end` ظاهر می‌شود.

در مدار `main` یک قطعه‌ی `Clock` واقعی وجود دارد؛ کافی است با `Ctrl+K` تیک بزنی.

## چیدمان و سیم‌کشی

تراشه‌ها با `facing = south` (عمودی) قرار گرفته‌اند تا پین‌ها روی دو لبه‌ی چپ و
راست بیفتند و جریان داده از چپ به راست باشد. هر پین با یک سیم کوتاه به یک تونل
نام‌دار می‌رود؛ طول این سیم‌ها یک‌درمیان ۳۰ و ۹۰ واحد است تا بدنه‌ی تونل‌ها
هرگز به هم نزدیک نشوند. ورودی‌ها و خروجی‌ها با اسپلیتر و سیم مستقیم بسته شده‌اند.

فایل با اسکریپت [`build_circ.py`](build_circ.py) تولید می‌شود؛ همان اسکریپت دو
بررسی هندسی هم انجام می‌دهد:

- هم‌پوشانی **هم‌راستا** (collinear) بین سیم‌های دو نت متفاوت و تماس نقطه‌ی
  انتهایی یک سیم با بدنه‌ی سیم دیگری — همان اتصال کوتاه خاموشی که در Lab02 دیده شد.
- برخورد جعبه‌ی محیطی قطعات با یکدیگر و عبور سیم از داخل بدنه‌ی تراشه‌ها.

هر دو بررسی روی فایل نهایی پاک هستند.

```bash
python3 build_circ.py
```

## نکات پیاده‌سازی

- MCP لاجسیم کتابخانه‌ی TTL را پشتیبانی نمی‌کند؛ تراشه‌ها مستقیم در XML نوشته
  شده‌اند (`<lib desc="#TTL" name="7"/>` و `<comp lib="7" name="74283"/>`).
- مختصات پین DIP از `AbstractTtlGate.updatePorts` استخراج شده است. برای
  `facing = south`، تراشه فضای `x−30 … x+30` و `y … y + 10·pinCount` را می‌گیرد و
  پین `p` اینجاست:
  - `p ≤ pinCount/2` → `(x − 30, y + 20·(p−1) + 10)`
  - `p > pinCount/2` → `(x + 30, y + 10·pinCount − 20·(p − pinCount/2 − 1) − 10)`
- پین‌های GND (`pinCount/2`) و VCC (`pinCount`) وقتی صفت `VccGndPorts` خاموش
  است پورت ندارند، ولی بقیه‌ی پین‌ها مختصات فیزیکی خودشان را حفظ می‌کنند.
- در `74194` لاجسیم، `QA` پرارزش‌ترین بیت و `QD` کم‌ارزش‌ترین است (مطابق دیتاشیت:
  شیفت راست از `QA` وارد می‌شود). در `74161` برعکس، `QA` بیت صفر است.
